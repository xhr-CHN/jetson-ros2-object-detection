## 结论与限制

模型在独立测试集上的总体 Precision 和 Recall 均超过课程要求的80%正确识别率参考线，但该自动测试指标不能替代“20个实际物体”的人工验收。增强测试集包含更多复杂网球场景，网球 Recall 和 mAP@0.5:0.95 仍低于铅笔，后续应重点保存网球漏检或定位不准案例，并在实际摄像头场景中测试两类物体同时出现的情况。
