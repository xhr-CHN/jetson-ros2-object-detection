# Jetson ROS 2 目标检测实验

## 实验目标

- 自行采集和标注不少于两类桌面物体的数据。
- 训练目标检测模型并部署到 Jetson。
- 实时显示目标类别、检测框和置信度。
- 通过 ROS 2 发布识别结果。
- 测试不少于 20 个物体，正确识别率不低于 80%。
- Jetson 实时检测速度不低于 5 FPS。
- 保存测试结果及典型错误案例。

## 初始检测类别

- 水杯（cup）
- 鼠标（mouse）

## 项目结构

```text
dataset/    自采图片、标签和数据集配置
models/     模型说明及部署产物
src/        训练、推理和测试程序
ros2_ws/    ROS 2 工作空间
results/    测试结果、正确案例和错误案例
report/     LaTeX 实验报告
docs/       运行说明、截图和演示材料
```
