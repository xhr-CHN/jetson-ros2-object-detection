# Roboflow 数据补充与增强训练设计

## 目标

将 `E:\Downloads\pencil.v2i.yolo26.zip` 和 `E:\Downloads\tennis ball.v1i.yolo26.zip` 安全补充到现有两类 YOLO 数据集，重新训练 YOLO26n，并在相同测试集上比较旧模型与新模型。只有新模型确有增强且满足课程指标时，才替换仓库中的最佳权重。

## 已验证输入

铅笔压缩包包含 94 张图片：训练集 75 张、验证集 19 张，共 97 个目标。源数据定义五个类别 `pencil-1` 至 `pencil-5`，许可证为 CC BY 4.0。

网球压缩包包含 352 张图片：训练集 246 张、验证集 70 张、测试集 36 张，共 402 个目标。源数据定义一个类别 `tennis-ball`，数据集说明标记为 Public Domain。

两个压缩包的图片与标签均一一对应，YOLO 行均为五列，类别编号和归一化坐标合法。

## 类别映射

项目类别保持不变：

```text
0: pencil
1: tennis_ball
```

铅笔源类别 `pencil-1`、`pencil-2`、`pencil-3`、`pencil-4`、`pencil-5` 全部映射为 `0=pencil`。网球源类别 `tennis-ball` 从源编号 0 映射为 `1=tennis_ball`。

## 合并规则

- 源 `train` 合并到项目 `train`。
- 源 `valid` 合并到项目 `val`。
- 源 `test` 合并到项目 `test`。
- 新文件使用 `roboflow_pencil_` 或 `roboflow_tennis_` 前缀，避免覆盖现有文件。
- 不修改现有样本的文件名、标签或划分。
- 在写入前校验图片可解码、图片与标签同名、每个目标框合法且非空。
- 使用文件 SHA-256 和解码后像素 SHA-256 检查重复；若新样本与现有样本重复，则保留现有样本并跳过新样本。
- 若新压缩包内部发生跨划分重复，保留优先级为 `test`、`val`、`train`，避免评估图片进入训练集。
- 合并脚本必须可重复运行：再次运行时先清理自己生成的 `roboflow_pencil_` 和 `roboflow_tennis_` 文件，再根据两个 ZIP 重建，不影响原始数据。

预计在没有重复样本时新增 446 张图片，合并后共 895 张；实际数量以去重报告为准。

## 来源与版本记录

更新 `dataset/SOURCES.md`，记录 Roboflow 项目名称、版本、URL、许可证、导出日期、原始类别和本项目映射。两个 ZIP 不提交仓库；只提交整理后的 YOLO 数据、可复现合并脚本、统计报告和来源说明。

脚本生成机器可读的 `dataset/augmentation-report.json`，包含每个来源/划分的输入、添加、跳过重复、目标数和最终总计。`dataset/data.yaml` 与 `dataset/data-windows.yaml` 继续引用相同目录和两类名称。

## 增强训练

先运行 3 个 epoch 的冒烟测试，确认扩充数据、CUDA 和标签无错误。正式训练从原始预训练 `yolo26n.pt` 开始，而不是从旧的项目最佳权重继续训练，以便与旧实验保持可比较；训练参数仍为 100 epochs、640 图像尺寸、batch 8、CUDA 设备 0、早停 20。

新训练输出使用独立名称 `pencil_tennis_yolo26n_augmented`，不覆盖旧训练结果或 `models/pencil_tennis_yolo26n_best.pt`。

## 模型比较和替换

合并完成后，测试集增加了未参与训练和最佳轮次选择的 Roboflow 网球测试图片。旧模型和增强模型都必须在同一份最终测试集上重新评估。

新模型替换旧最佳权重需同时满足：

- 测试集总体正确识别表现继续满足课程 80% 要求；
- 总体 `mAP@0.5:0.95` 高于旧模型在相同测试集上的结果；
- 两个类别的 Recall 均不比旧模型低超过 0.02；
- 模型仍可由 Windows 摄像头程序正常加载。

若不满足替换条件，保留旧最佳权重，同时保留增强训练结果和比较报告，便于调整数据或训练参数。

## Git 提交策略

使用独立增量提交：

1. 数据来源、合并脚本和整理后的数据；
2. 增强训练脚本配置；
3. 训练产物与同测试集比较报告；
4. 仅在通过替换标准时更新正式最佳模型。

大型临时 ZIP、训练缓存和非必要中间权重不提交 GitHub。

## 验证标准

- 合并前后现有样本不被意外修改。
- 全部图片可解码，全部图片/标签一一对应。
- 所有标签只含类别 0 或 1，坐标在 `[0, 1]` 且框宽高大于 0。
- 训练、验证、测试之间不存在脚本可检测到的重复图片。
- 统计报告与磁盘文件数量一致。
- 冒烟训练通过后才启动正式训练。
- 新旧模型在同一测试集上比较后才决定是否替换。
