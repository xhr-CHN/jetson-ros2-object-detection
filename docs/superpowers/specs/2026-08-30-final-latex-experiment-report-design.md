# 最终 LaTeX 实验报告设计

## 1. 目标与范围

为“实验一：目标检测与识别”制作一份约14–18页的中文课程实验报告。报告必须严格使用本项目已经完成的实验、真实数据和真实运行记录，覆盖数据集、训练、独立测试、Jetson部署、ROS 2发布、40项最终验收、典型错误、GitHub仓库与commit记录。

报告交付物包括可编辑LaTeX源文件、参考文献、图像资源、编译说明和经过逐页视觉检查的PDF。报告完成后形成独立Git提交并同步GitHub。

封面姓名、学号和班级按用户要求保留空白栏，不使用“待定”或虚构身份。

## 2. 作业要求映射

| 作业要求 | 报告对应内容 |
|---|---|
| 不少于2类桌面物体 | `pencil`与`tennis_ball`两类 |
| 数据采集、标注与训练 | 公开数据来源、类别合并、YOLO转换、划分、100轮训练 |
| Jetson运行 | Jetson Orin、TensorRT Engine、真实环境和模型哈希 |
| 实时显示类别、检测框和置信度 | 检测结果图、视频抽帧和推理程序说明 |
| ROS 2发布识别结果 | 检测节点、三个话题和消息格式 |
| 不少于20项、正确率不低于80% | 第二次最终验收20张铅笔+20张网球，39/40，97.5% |
| Jetson不低于5 FPS | 图像话题最低13.369 FPS；检测数据最低15.421 FPS |
| 保存结果和典型错误 | CSV、JSON、39张正确图、1张漏检图及错误分析 |
| GitHub链接与commit记录截图 | 真实公开仓库页面和真实commits页面截图 |
| LaTeX自定义模板 | 自定义黑白单栏`ctexart`模板 |

项目使用公开数据集而非全部自行拍摄。报告将如实写明数据来源、许可证和处理过程，不把公开数据描述为自行采集。

## 3. 版式设计

- A4纸、单栏、从左到右及从上到下顺序排版，不使用左右分栏或彩色信息卡。
- 全文纯黑白。
- 总标题直接使用黑体居中。
- 正文使用小四号宋体，英文和数字优先Times New Roman，1.5倍行距。
- 一级、二级、三级标题层级清楚，目录自动生成。
- 表题置于表上，图题置于图下，图表统一编号并交叉引用。
- 所有数据表使用`booktabs`标准三线表，不使用竖线、底色或彩色强调。
- 代码仅展示必要片段，使用黑白等宽字体；完整实现通过仓库路径和GitHub链接说明。
- 页眉简洁显示实验名称，页脚居中显示页码。

模板使用XeLaTeX。中文字体优先宋体和黑体，缺少Windows字体时分别回退FandolSong与FandolHei；英文字体优先Times New Roman，缺失时回退TeX Gyre Termes。

## 5. 真实数据口径

### 5.1 数据集

- 最终图片总数：895
- 训练集：605张，铅笔317个目标，网球387个目标
- 验证集：171张，铅笔100个目标，网球94个目标
- 测试集：119张，铅笔80个目标，网球70个目标
- 总目标数：铅笔497，网球551
- 类别映射：`0=pencil`，`1=tennis_ball`

来源包括Mendeley网球数据、Kaggle铅笔数据和两个Roboflow补充数据。报告列出链接、版本、许可证与类别映射；Kaggle铅笔数据许可证未知的限制必须保留。

### 5.2 训练与验证

- 模型：YOLO26n
- 输入：640×640
- 训练：100轮，批量8，NVIDIA GeForce RTX 4060 Laptop GPU
- 最佳轮次：87
- 最佳验证Precision：0.96338
- 最佳验证Recall：0.97329
- 最佳验证mAP@0.5：0.98185
- 最佳验证mAP@0.5:0.95：0.88025

### 5.3 独立测试集

- 图片：119张，未参与训练或最佳权重选择
- 总体Precision：0.98877
- 总体Recall：0.90186
- 总体mAP@0.5：0.97148
- 总体mAP@0.5:0.95：0.87761
- 铅笔mAP@0.5:0.95：0.95422
- 网球mAP@0.5:0.95：0.80101

### 5.4 Jetson实时性能

- 设备：Jetson Orin，aarch64，Jetson Linux R36.4.3
- CUDA：12.6；TensorRT：10.3.0；ROS 2：Humble
- `/detection/image`话题：13.369–14.092 FPS，平均13.795 FPS
- `/detection/fps`数据：15.421–17.971 FPS，平均16.657 FPS
- 两种实时记录均超过5 FPS要求

### 5.5 第二次最终验收

- 第一次10+10项仅作为初步记录
- 第二次才是最终验收：20张铅笔、20张网球，共40张互不重复测试图片
- 铅笔：19/20，95.0%
- 网球：20/20，100.0%
- 总计：39/40，97.5%
- 平均离线TensorRT模型速度：31.7906 FPS
- 最低离线TensorRT模型速度：30.1659 FPS
- 唯一错误：`pencil_red4.jpg`漏检，预测为`none`

报告必须明确：97.5%是40项分类式验收正确率；mAP来自完整独立测试集；30.17–31.79 FPS是静态图片离线TensorRT速度；13.37–14.09 FPS更接近摄像头采集、绘制和ROS 2发布的端到端速度。

## 9. 编译与质量验收

1. 使用XeLaTeX完成至少两轮编译，确保目录和交叉引用稳定。
2. 检查编译日志，不保留未定义引用、图片缺失、文字越界或表格溢出。
3. 使用Poppler将最终PDF逐页渲染为PNG。
4. 逐页检查中文字体、英文数字字体、黑白效果、三线表、标题层级、页码、图题、表题和图片清晰度。
5. 使用PDF文本提取检查总页数、章节标题、关键数据和GitHub链接。
6. 检查最终PDF中没有占位文字；姓名、学号和班级仅保留有标签的空白栏。
7. 检查最终Git差异不包含编译缓存、浏览器临时文件或其他无关内容。
8. 报告形成独立commit，最终验证后推送GitHub。
